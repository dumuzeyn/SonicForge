SonicForge · Help

Add audio to the editor and select a clip. Hold the right mouse button and drag to select a range. Ctrl + wheel zooms in or out. The main tools are fade in, fade out, transition to the next song on the same track, selection, split and delete. Right-click an icon for its name and description.

Ctrl+Z: undo; Ctrl+Y: redo; Ctrl+K: split; Delete: delete; Ctrl+E: export. Space plays the mix when the timeline has focus. The settings icon opens clip volume, trim, position, duplicate and new project actions.

Link editor uses the current mix as the source for the other tabs. Switching tabs, changing tracks and toggling this setting preserves the lyrics and timestamps you entered.

Lyrics has playback and seeking. F8 places a cue 100 ms before the current sound and moves to the next nonempty line. Manually entered timestamps are exact. Timing correction keeps your supplied words and repeated lines, using word alignment where a match is found.

Processing writes copies into the output folder. It preserves the original audio files. The dedicated Save lyrics action can update the selected MP3's lyric tag directly. Choose LRC or TXT for a separate text file.

Whisper, HTDemucs and genre models run locally. Release packages include the models; missing models can be downloaded and their checksums are verified. Recognition can make mistakes. Listen and review the result before saving.

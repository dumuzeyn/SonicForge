# SonicForge 3.2.0

Музыкальный редактор для Windows: монтаж на дорожках, обработка звука, метаданные, процедурные обложки и синхронизированный текст песен. Приложение написано на **C++20 / Qt 6**; распознавание, выравнивание текста и разделение на составляющие выполняются локально. Python для запуска не нужен.

**Система:** Windows 10/11 x64. Qt, FFmpeg и необходимые runtime входят в комплект. Нейросетям нужен процессор с AVX2 и несколько гигабайт свободной оперативной памяти. Обычный выпуск использует CPU; режим Whisper Turbo требует меньше памяти, чем Large.

Установщик и портативный ZIP не содержат тяжёлых моделей распознавания, выравнивания и разделения. При первом использовании соответствующей функции приложение загружает модель в пользовательскую папку и проверяет SHA-256. Для этого нужен интернет; после загрузки модель используется локально. Такой комплект подходит под ограничение размера файлов GitHub Releases и не заставляет скачивать все модели для работы с тегами или монтажом.

Файлы выпуска **не подписаны Authenticode**: сертификата издателя пока нет. SHA-256 позволяет сверить целостность с опубликованным списком, но не заменяет доверенную подпись издателя. Проверить скачанный файл в PowerShell:

```powershell
Get-FileHash .\SonicForge-Setup.exe -Algorithm SHA256
```

## Что нового в 3.2.0

- Проекты `.sfproject`: сохранение монтажа, текста с таймкодами, настроек и оформления обложки; автосохранение и восстановление незавершённой сессии.
- Резервные копии заменяемых TXT/LRC и экспорта, атомарная запись и защита исходников по SHA-256. Ошибки отдельных файлов в пакете выводятся в отчёт.
- Сохранение SYLT и языковых версий текста MP3, пересчёт таймкодов при изменении скорости, строгая проверка повреждённых ID3.
- Экспорт больших монтажей без переполнения командной строки Windows и бесконечного дописывания тишины. Внутри используется float PCM; доступны выбор частоты, каналов и битности WAV, FLAC и Opus.
- Предпрослушивание выбранного фрагмента с конечным кодеком и качеством. При обработке с лимитером true peak проверяется после кодирования.
- Быстрая отрисовка видимой части таймлайна, ограниченная история отмены, точный числовой ввод, обычное меню копирования и вставки, сохранение аудионастроек.
- Регистрация в установленных приложениях Windows, ярлык удаления в «Пуск», отдельный деинсталлятор и компактная поставка моделей по требованию.

## Возможности

**Монтаж.** Дорожки с прокруткой, импорт перетаскиванием, перемещение, разделение, дублирование, выделение и удаление фрагментов. Громкость и скорость, трёхполосный эквалайзер, плавные края и переход между соседними песнями. Экспорт WAV, MP3, M4A, FLAC и Opus. Отмена и повтор до 100 изменений.

**Звук.** Нормализация громкости, лимитер, эквалайзер, компрессор, фильтры, шумоподавление, скорость, высота тона, стереобаза, реверберация и затухания. Два плеера сравнивают исходный и обработанный фрагмент; зелёные отметки показывают изменённые участки. Автоматическое шумоподавление экспериментальное и выключено по умолчанию.

**Метаданные.** MP3/ID3, FLAC, M4A, Ogg и Opus, встроенные обложки, текст и отдельные файлы TXT/LRC. Изменение одной языковой версии MP3-текста сохраняет остальные. Неподдерживаемое встраивание явно отклоняется.

**Обложки.** Три семейства процедурной графики Music2Picture: спектральные контуры M2Pv1, органические формы M2Pv2 и фактура M2Pv3 с развитием по времени. Цвет M2Pv3 отражает локальную скорость и плотность ритма. Доступны 66 центральных символов, своя палитра, импорт изображения, шрифты, расположение надписи и экспорт PNG. Этап «Обложка» в разделе «Выполнение» встраивает результат в выходной аудиофайл.

**Текст песен.** Ручные метки во время прослушивания, Whisper Large v3 и Turbo, прямое выравнивание готового русского или английского текста по аудио. Коррекция сохраняет заданные слова и повторы. HTDemucs выделяет вокал/инструментал или четыре составляющие; MSD musicnn определяет жанровые метки по участкам записи. Автоматическое назначение жанра включается отдельно.

Русский и английский интерфейс. Контекстная справка доступна правым кликом по инструментам.

## Установка, обновление и удаление

1. Запустите `SonicForge-Setup.exe`. Установка выполняется для текущего пользователя в `%LOCALAPPDATA%\Programs\Sonic Forge`; повторный запуск обновляет существующую копию. Перед обновлением закройте приложение: установщик не завершает открытую сессию принудительно.
2. Откройте **Sonic Forge** через «Пуск». Программа также появится в «Параметры → Приложения → Установленные приложения».
3. Для удаления используйте список приложений Windows, пункт **«Удалить Sonic Forge»** в «Пуск» или отдельный `SonicForge-Uninstall.exe`. Настройки и пользовательские аудиофайлы сохраняются.

Портативный ZIP нужно распаковать целиком и запустить `SonicForge/SonicForge.exe`. Такая копия не регистрируется в списке установленных приложений; отдельный деинсталлятор предназначен для установленной версии.

## Работа и сохранение

Добавьте файлы в редактор. Флажок **«Связь с редактором»** передаёт монтаж остальным вкладкам; при выключенной связи они используют отдельный выбранный файл. Раздел **«Выполнение»** применяет отмеченные этапы к копиям в папке результата. «Сохранить текст» может записать текст непосредственно в выбранный MP3 с резервной копией либо сохранить TXT/LRC.

**Ctrl+S** сохраняет проект, **Ctrl+O** открывает его. Папку `.sfproject.assets` переносите вместе с проектом: она содержит созданное приложением аудио и фон обложки. Пути к внешним исходникам сохраняются по прежним адресам; эти файлы также должны оставаться доступными. Копии заменённых файлов находятся в соседней папке `.sonicforge-backups`.

| Действие | Управление |
|---|---|
| Добавить аудио | Ctrl+I |
| Разделить / дублировать | Ctrl+K / Ctrl+D |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z |
| Экспорт монтажа | Ctrl+E |
| Масштаб таймлайна | Ctrl + колесо |
| Выделить диапазон | Перетаскивание правой кнопкой |
| Выбрать соседний фрагмент | Page Up / Page Down |
| Переместить курсор / выбранный фрагмент | Стрелки / Shift + стрелки |
| Поставить метку следующей строки | F8, с опережением звука на 45 мс |

Распознавание, выделение вокала и жанровые метки могут ошибаться. Проверяйте результат прослушиванием и при необходимости исправляйте текст и таймкоды вручную. Словарь жанров ограничен обученной моделью; пресет громкости не является оценкой художественного качества записи.

## Сборка из исходников

Нужны Windows x64, Git, CMake 3.24+, Ninja и FFmpeg (`ffmpeg.exe` / `ffprobe.exe`). Установите Qt 6.10.0 MinGW 13.1 x64 с модулями Multimedia, SVG и Image Formats в `build/qt/6.10.0/mingw_64`, компилятор — в `build/qt/Tools/mingw1310_64`. CMake и Ninja должны быть в PATH либо в `build/native-tools/cmake/bin` и `build/native-tools/bin`. Для Setup нужен Inno Setup 6.

```powershell
# Компиляция и CTest
.\scripts\build_native.ps1

# Единственный комплект dist/SonicForge, установщик, деинсталлятор и ZIP
.\scripts\build_native.ps1 -Deploy -Installer -Portable -FfmpegRoot C:\ffmpeg
```

Версии и хеши закреплены в `native/dependencies.json`, `native/runtime-lock.json` и `native/resources/models.json`. Нейросетевые модели для локального комплекта берутся из `build/native-models`; выпущенный ZIP исключает тяжёлые модели. `build-info.json` и `build-manifest.json` связывают бинарные файлы с исходниками и Git-коммитом. Комплект проверяется в `build` перед заменой канонической папки; установщик и ZIP также заменяются подготовленными файлами.

Whisper можно собрать с Vulkan через `-WhisperVulkan` при наличии Vulkan SDK и совместимого драйвера. Этот вариант отдельно не проверялся; обычная сборка использует CPU. `SF_CPU_ONLY=1` отключает GPU в поддерживающей его сборке. HTDemucs и жанровая модель используют CPU.

Для Authenticode задайте `SF_SIGN_CERT_SHA1` и установите Windows SDK SignTool. Без сертификата файлы остаются неподписанными. Скрипт публикации требует чистого рабочего дерева, совпадения коммита, манифестов и контрольных сумм; неподписанный выпуск публикуется с явным `-AllowUnsigned`.

Кэш разделён по сессиям и защищён блокировками; неактивные сессии очищаются. Квота по умолчанию 8 GiB, параметр QSettings `cache/maxGiB`. Старые временные файлы прежних версий автоматически не удаляются.

## Проверки

- CTest: ядро, регрессии надёжности и GUI, включая проекты, таймкоды, повреждённые теги, отмену, сохранность файлов и большой монтаж.
- `scripts/check_native.ps1`: готовый комплект с системным PATH, настоящий плеер, текст, обложки, звук и корректное закрытие. `-Neural` добавляет прямое выравнивание и четыре стема.
- `scripts/check_installer.ps1 -FullPayload`: изолированная установка настоящего комплекта, обновление, запись Windows, ярлыки и удаление с сохранением пользовательского файла.
- `scripts/check_lyrics_quality.ps1 -Full`: синтетическая русская и английская речь с Large; `-RecognitionModel turbo` проверяет Turbo. Тяжёлые нейросетевые тесты запускайте последовательно.
- GitHub Actions: проверка PowerShell/JSON и сборка самостоятельного деинсталлятора на Windows.

Python не требуется ни приложению, ни сборке. Исходники прежней Python-версии доступны в истории Git и теге `v3.0.0`.

## English

SonicForge 3.2.0 is a native C++20 / Qt 6 audio editor for Windows 10/11 x64. It includes multitrack editing, audio processing, metadata, procedural cover artwork and timed lyrics. Recognition, alignment, stem separation and genre inference run locally; no Python runtime is shipped.

Download the [installer](https://github.com/dumuzeyn/SonicForge/releases/download/v3.2.0/SonicForge-Setup.exe), [portable ZIP](https://github.com/dumuzeyn/SonicForge/releases/download/v3.2.0/SonicForge-windows-x64.zip) or [standalone uninstall launcher](https://github.com/dumuzeyn/SonicForge/releases/download/v3.2.0/SonicForge-Uninstall.exe). Large neural models download on first use and are checked with SHA-256. Neural functions require AVX2 and several gigabytes of available RAM. The release is unsigned. Save projects with Ctrl+S, open them with Ctrl+O, and keep their `.assets` folder and external source files available.

# SonicForge 3.2.1

[English release notes](https://github.com/dumuzeyn/SonicForge/blob/v3.2.1/docs/RELEASE-3.2.1.en.md)

- При обработке метаданных автоматически выбирается один жанр с максимальной оценкой модели, даже при низкой уверенности. Введённое вручную значение имеет приоритет; альтернативы остаются в журнале.
- Монтаж из одной песни сохраняет имя исходного файла в названии результата и метаданных. Это работает и после разрезания песни на фрагменты или добавления её составляющих на отдельные дорожки.
- При выборе папки результат по умолчанию сохраняется в соседнюю `SonicForgeProgect`, на одном уровне с исходной папкой.
- Палитра M2Pv3: медленные участки — сине-фиолетовые, средние — сине-зелёные, быстрые — красные. Цвет следует местному ритму по ходу песни.
- Переработан анализ темпа: учитываются устойчивые акценты, изменения спектра и затухание ударов. Частые ноты медленной мелодии больше не заставляют автоматически выбирать удвоенный или утроенный темп. Цвет и фактура используют одну оценку ритма.

Проверены три набора CTest, готовая сборка с системным PATH, установка, обновление и удаление полного комплекта с сохранением пользовательских файлов. Регрессии охватывают медленную мелодию с частыми нотами, быстрые ударные поверх тянущихся аккордов, изменение темпа, разные уровни громкости и стационарный шум. На проверенной записи `Fallen Down` новая оценка основного пульса — около 66 BPM.

## Файлы выпуска

- `SonicForge-Setup.exe` — установка и обновление для текущего пользователя Windows.
- `SonicForge-Uninstall.exe` — запуск стандартного удаления установленной версии.
- `SonicForge-windows-x64.zip` — портативная версия; распакуйте целиком и запустите `SonicForge/SonicForge.exe`.
- `SHA256SUMS.txt` — контрольные суммы SHA-256 трёх файлов выше.

Тяжёлые модели Whisper, CTC и HTDemucs загружаются по требованию и проверяются по SHA-256. Жанровая модель входит в комплект. Файлы выпуска не подписаны Authenticode: сертификат издателя пока не настроен.

# SonicForge 3.0.0 — приложение на C++

Приложение полностью переведено на C++20 / Qt 6: интерфейс, монтаж, обработка файлов, обложки, текст, распознавание, разделение на инструменты и определение жанров. Python не входит в поставку и не требуется для запуска.

- Область дорожек сокращена до 225 px и прокручивается при добавлении дорожек.
- Сделаны собственные векторные иконки. Название и описание инструмента открываются правым кликом.
- Основные инструменты расположены в порядке: плавное начало, плавный конец, плавный переход, выделение, разделение, удаление. Переход соединяет выбранную песню со следующей на той же дорожке с выравниванием громкости у стыка.
- Выделение работает удержанием правой кнопки мыши, масштабирование — Ctrl + колесо.
- Текст и таймкоды сохраняются при смене вкладок, режима связи и правках монтажа. Удалены черновик и большая панель параметров фрагмента.
- Во вкладке «Текст» есть прослушивание и перемотка. F8 ставит таймкод с упреждением 0,1 секунды и переходит к следующей строке. Коррекция использует временные метки слов и сохраняет пользовательский текст.
- Перенесены обработка звука, метаданные и обложки, A/B-прослушивание, пакетная обработка, три генератора обложек и редактор палитры с перетаскиванием точек.
- Whisper, HTDemucs и модель жанров включены в поставку. Нативные рабочие процессы запускаются из того же EXE.

Для установки скачайте **SonicForge-Setup.exe**. Для запуска без установки распакуйте **SonicForge-windows-x64.zip** целиком. Проверочные суммы находятся в **SHA256SUMS.txt**. Windows 10/11 x64; для распознавания речи нужен AVX2 и несколько гигабайт свободной памяти.

При обновлении установщик сохраняет прежний путь установки. Старый Python runtime удаляется из каталога установленного приложения. Исходники версии 2 сохранены в `legacy/python-v2`.

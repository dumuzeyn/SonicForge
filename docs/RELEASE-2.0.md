# SonicForge 2.0

## Русский

- Многодорожечный редактор: импорт на отдельные дорожки, точное выделение, разрезы, удаление диапазона, отмена/повтор, черновики и экспорт.
- Локальное разделение вокала и инструментов на 2 или 4 составляющие.
- Упрощённая панель звука со сглаженными ползунками, анализом и сравнением; точные настройки темпа, высоты и эффектов.
- Пять процедурных вариантов Music2Picture и собственные PNG/JPEG/WebP для обложки.
- Перепроверка сомнительных слов и вступления; русская транскрипция иностранных языков по умолчанию, ручная проверка текста.
- Классические разделы, справка, настройки языка и прозрачная заставка с актуальной иконкой. Страницы не пересоздаются при переключении.
- Проверки локальных файлов, безопасный запуск медиапроцессов и сохранение исходников при пакетной обработке.
- README на русском и английском: инструкции, параметры и скриншоты рядом с соответствующими инструментами.
- Некоммерческая и образовательная лицензия собственного кода; сторонние компоненты сохраняют свои условия.

### Установка

Скачайте **SonicForge-Setup-2.0.0.exe** и запустите установщик. Windows x64, установка для текущего пользователя. Отдельный Python не нужен. Перед обновлением сохраните черновики и закройте приложение.

Портативный архив **SonicForge-2.0.0-windows-x64.zip** нужно распаковать целиком; запускайте SonicForge/SonicForge.exe, не удаляя _internal.

Обработка звука, обложки и разделение работают локально. Первое распознавание текста требует загрузки весов; качество расшифровки и разделения не гарантируется. Проверьте результаты перед сохранением. Файл SHA256SUMS.txt позволяет сверить загруженные файлы.

## English

- Multitrack editing: separate import lanes, precise ranges, splits, range removal, undo/redo, drafts and export.
- Local two- or four-component stem separation.
- Clearer Audio workspace with smooth sliders, analysis and comparison; precise tempo, pitch and effects controls.
- Five procedural Music2Picture variants and custom PNG/JPEG/WebP cover images.
- Rechecking uncertain words/introductions, default Russian sound spelling for foreign languages, manual lyric review.
- Classic tabs, contextual help, language settings and a transparent splash using the current icon. Pages are persistent across switches.
- Local-media validation, safe media-process argument handling and source preservation during batch processing.
- Illustrated Russian and English guides with screenshots placed next to the relevant instructions.
- Noncommercial/educational terms for original project works; third-party licenses remain unchanged.

Download **SonicForge-Setup-2.0.0.exe** for a per-user Windows x64 installation. Save drafts and close the app before updating. No separate Python installation is needed.

For the portable **SonicForge-2.0.0-windows-x64.zip**, extract the entire archive and keep _internal beside SonicForge/SonicForge.exe. Initial speech recognition downloads weights. Recognition and separation are approximate; review results. Verify downloads against SHA256SUMS.txt.

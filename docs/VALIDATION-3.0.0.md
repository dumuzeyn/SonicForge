# Проверка SonicForge 3.0.0

Проверено 19 октября 2026 года на Windows x64. Сборка: C++20, Qt 6.10.0, MinGW 13.1.0, Release.

В QtTest прошли **15 проверок, 0 ошибок**. Проверялись модель монтажа и разделение, запрет пересечений, LRC с заголовками и смещением, FFT, SVG-иконки, теги MP3 с побайтовым сохранением исходного звукового потока, метаданные и обложки FLAC/M4A/Ogg/Opus с неизменным декодированным звуком, отдельный LRC и встроенный текст, реальный экспорт с плавными краями, соединение песен и вырезание, двухпроходная нормализация и отмена, воспроизводимость трёх генераторов обложек и транслитерация.

Проверка интерфейса подтвердила сохранение текста при переключении всех вкладок, включении связи с редактором, изменении дорожки и отмене; высоту дорожек 225 px; масштабирование; переход к следующей строке и упреждение ручной метки F8 на 100 мс. Название и описание неактивной иконки открывались настоящим событием контекстного меню. Сняты и просмотрены изображения русского и английского интерфейса.

Портативное приложение запускалось с `PATH`, содержащим только системные каталоги Windows. Плагины Qt и FFmpeg загружались из поставки. Проверены платформа Windows и offscreen. В каталоге приложения отсутствуют Python, `.py`, `.pyc`, `.pyd` и прежний `_internal`.

Проверка реального QMediaPlayer прошла: старт с курсора 1,2 с, пауза, перемотка и продолжение с 2,8 с, сброс старого микса после правки, воспроизведение связанного монтажа в тексте и F8 с упреждением 0,1 с. Тестовый вывод был заглушён.

Нативный ONNX Runtime загрузил закреплённую модель MSD musicnn и выполнил классификацию. Whisper large-v3-turbo распознал проверочную речь; коррекция сохранила четыре заданные строки с собственными границами, хотя исходная запись содержала два предложения. HTDemucs создал четыре звуковые составляющие 44,1 кГц / стерео. Проверки выполнялись без установленного Python в пути поиска приложения.

Проверочные команды:

```powershell
.\scripts\build_native.ps1
.\scripts\check_native.ps1 -Neural
```

Отчёты и журналы создаются локально в `validation`, они не входят в приложение. Эти проверки подтверждают работу движков и регрессии интерфейса; качество распознавания конкретной песни зависит от записи.

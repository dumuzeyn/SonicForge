# Проверка SonicForge 3.1.0

Проверено на Windows x64, Qt 6.10.0 / MinGW 13.1. Сборка использовала самостоятельные CMake и Ninja без запуска Python.

## Функциональные проверки

QtTest: 21 проверка, включая служебные начало/завершение, без ошибок. Проверены монтаж, метаданные и сохранение текста, аудиоэкспорт, нормализация, переходы, генерация обложек, отключение символа, скорость и громкость фрагмента, тишина при 0% скорости, волновая форма двухчасового файла и завершение дочернего процесса.

Диагностика интерфейса проверяет общую верхнюю панель, выбор формата без связи с редактором, ползунки фрагмента 0–400%, эквалайзер и сдвиг следующего фрагмента, свёрнутые панели, контекстные объяснения и сохранение текста. Плеер проверен с реальным файлом: старт с курсора, перемотка красной линией во время проигрывания, пауза и продолжение, воспроизведение во вкладке текста и F8 с упреждением 45 мс.

Плееры звука проверены отдельно: оригинал остаётся исходным файлом, изменённый результат создаётся автоматически, скорость из свёрнутой панели применяется, оба плеера воспроизводят и перематывают, одновременное проигрывание исключено.

При закрытии окна во время активной двухминутной задачи FFmpeg обработчик завершился, ожидание внутри закрытия заняло 4 мс. Проверен Windows Job Object с принудительным завершением принадлежащего приложению процесса. Это измерение конкретного запуска, время на другом компьютере может отличаться.

## Поставка и нейронные модели

Приложение проверено с PATH только из системных каталогов Windows. Qt, FFmpeg, ONNX Runtime и модели загружаются из поставки. Python, `.py`, `.pyc`, `.pyd` и `_internal` отсутствуют. В текущем дереве Git исходников Python нет; архив прежней версии доступен через тег v3.0.0.

Whisper сохранил четыре предоставленные строки с возрастающими границами. HTDemucs обработал запись 5,62839 секунды двумя блоками по три секунды с перекрытием. Все четыре результата имеют ту же длительность, 44,1 кГц, стерео. Контрольные суммы моделей закреплены в манифесте. Качество распознавания и разделения зависит от материала; короткая проверочная запись не оценивает качество на всех жанрах.

## Память

Whisper Large v3 и CTC проверены на русской синтетической записи с тремя фразами, вступлением и паузами: ошибка слов 0%, максимальная ошибка начала фразы до применения упреждения — 40 мс. Пиковый Working Set распознавания — 2109,5 МБ, выравнивания — 657 МБ. Это контрольный сценарий, а не оценка качества на любых песнях. Повторный запуск остановлен перед выпуском по просьбе пользователя; проверка английского распознавания отложена. Полная проверка английского выравнивания выявила проблему на длинной тишине; добавлено разбиение тишины, итоговая английская проверка не выполнялась.

Упреждение автоматических меток и F8 — 45 мс. Точность распознавания начала звука влияет на итоговую точность метки; постоянное смещение само по себе не гарантирует совпадение с каждым вокальным вступлением.

Измерены пиковые Working Set и Private Bytes отдельного проверяемого процесса. Память внешнего FFmpeg не включена в эти значения.

Отдельная проверка волновой формы двухчасовой записи: 16,4 МБ Working Set, не более 2401 точки волновой формы. HTDemucs хранит не более 62 секунд входного аудио и соответствующих выходов; запись WAV выполняется блоками 64 КиБ. Анализ обложки хранит фиксированные спектральные столбцы и короткое окно ритма. Размер рабочих изображений ограничен 640 px до финального масштабирования.

Память моделей остаётся необходимой: на компьютере без достаточного свободного объёма обработка нейронными моделями может быть недоступна. Устранён рост аудиобуферов пропорционально длительности всей песни; отсутствие ошибок при любых ресурсах не гарантируется.

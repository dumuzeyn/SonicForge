## Проверка итоговых файлов

Финальная проверка завершена 27 октября 2026 года. Версия **3.2.0**, идентификатор исходников **`33f2f165da9c4c529acd909eff39f205e68f11b55627f45cef78796974bdf02a`**.

- Все три набора CTest прошли: `native_core`, `reliability_core`, `reliability_gui`. Последняя правка GUI проверена повторно. Отчёт: `validation/build-final.log`.
- Готовый комплект прошёл проверки интерфейса, настоящего воспроизведения, TXT/LRC/MP3, обложки, обработки звука, анализа и закрытия с отменой при системном PATH, без Qt SDK и Python. Отчёты: `validation/packaged-native`.
- Прямое выравнивание готового текста и выделение четырёх стемов прошли. Все четыре WAV дополнительно проверены через FFprobe: **stereo, 44 100 Hz, 32-bit float**, одинаковая длительность 5,628390 секунды. Отчёт: `validation/stems-final.json`.
- Проверены русское и английское распознавание с **Whisper Large**, последовательно, без ошибки выделения памяти прежнего параллельного прогона. Пиковый рабочий набор — около 2,1 GiB на модель. Нейросетевое ядро не менялось при последней правке состояния GUI; его неизменный SHA-256 зафиксирован в `validation/verification-final.json`.
- Установка настоящего комплекта в изолированный каталог, повторное обновление, регистрация Windows, ярлыки, удаление и сохранение пользовательского файла прошли. Тест учитывает задержку самоудаления EXE Inno Setup. Отчёт: `validation/installer-check.json`.
- Основная установленная копия обновлена до **3.2.0** в `%LOCALAPPDATA%\Programs\Sonic Forge`. Проверены запись в установленных приложениях, ярлыки запуска и удаления, отсутствие дублированного деинсталлятора и поиск установленной копии отдельным `SonicForge-Uninstall.exe --check`.
- Проверены SHA-256 всех **94 файлов** комплекта и установленной копии, всех обязательных файлов внутри портативного ZIP и файла `SHA256SUMS.txt`. EXE установленной копии совпадает с EXE дистрибутива. Отчёты: `validation/distribution-final.json`, `validation/installed-final.json`, `validation/verification-final.json`.

Готовые файлы остаются в единственных стабильных местах: `dist/SonicForge`, `dist/SonicForge-Setup.exe` (около 178 MB), `dist/SonicForge-Uninstall.exe`, `dist/SonicForge-windows-x64.zip`. Манифесты и контрольные суммы согласованы с этой сборкой. Приложение, Setup и отдельный деинсталлятор имеют статус **NotSigned**; доверенная подпись не подменялась самоподписанным сертификатом. Публикация в GitHub выполняется отдельным шагом после проверки чистого коммита и контрольных сумм.

Автоматическая проверка действий заблокировала очистку служебного тестового кэша `reliability_tests/cache/edits`, указав только «blocked by policy». Эта папка оставлена на месте; в установку и портативный архив она не входит.

## Что требует внешних условий

- Доверенная Authenticode-подпись: нужен действующий сертификат издателя. Самоподписанный сертификат не подменяет доверенный.
- GPU-ускорение: нужен совместимый драйвер/SDK и проверка собранного Vulkan-backend. В текущий CPU-выпуск ускорение не обещается.
- Ошибки нейросетей: прослушивание, ручная правка и проверка таймингов остаются частью работы с результатом. Для расширения жанрового словаря нужна другая обученная модель и отдельная оценка качества.

Остальные строки таблицы описывают выполненные изменения, а не обещание отсутствия любых будущих ошибок.

## Упаковка для GitHub Releases

Для публикации 3.2.0 портативный ZIP приведён к поставке моделей по требованию, как Setup. Полный локальный каталог приложения сохраняет модели, но ZIP исключает пять необязательных файлов Whisper/CTC/HTDemucs. Их отсутствие разрешено манифестом; обязательные файлы проверяются по SHA-256. В SHA256SUMS.txt перечислены три непосредственно скачиваемых файла выпуска. Ссылки README ведут на v3.2.0.

# SonicForge 3.1.0

Обновлён интерфейс, исправлены перемотка и завершение приложения, снижено потребление памяти при работе с длинными песнями. Текущие исходники и сборка полностью на C++: архив Python удалён из ветки, прежние версии доступны в истории Git.

- Общая полоса меню на всю ширину над остальными элементами; заметный переключатель связи с редактором. Формат монтажа доступен независимо от связи.
- Исправлена иконка окна и панели задач; ресурс включён в EXE. Перемещение красной линии перематывает звук во время проигрывания и на паузе.
- В дополнительных настройках фрагмента появились ползунки громкости и скорости 0–400% и трёхполосный эквалайзер. 0% скорости создаёт паузу длительностью исходного фрагмента. Изменение длины сдвигает следующие фрагменты той же дорожки.
- Метаданные всегда сохраняют существующие текст и таймкоды. Подсказки в пустых полях объясняют выбор названия и жанра; переключатели перезаписи находятся рядом с чтением и очисткой.
- Настройки звука используют ползунки. Фильтры и эффекты сворачиваются, оставаясь активными для обработки, анализа и рекомендаций. Под настройками расположены плееры оригинала и автоматически обновляемого результата.
- Возвращены органические текстуры и анализ структуры всей песни для обложек. Параметры ниже Seed свёрнуты; надпись и символ можно отключить. Генераторы перенесены в C++, результат не обязан пиксельно совпадать со старой версией.
- Обновлены справка, контекстные описания и настройки со ссылками на GitHub и поддержку автора.
- Добавлен режим «Точнее»: полный Whisper Large v3, поиск нескольких вариантов слов и отдельное акустическое выравнивание русских и английских строк через Wav2Vec2 CTC. Режим «Быстрее» сохраняет Turbo. Модели работают последовательно, освобождая память перед следующим этапом.
- Склейка распознавания выполняется по словам: пересечение окон больше не удаляет целую фразу. Пропуски проверяются короткими окнами, слабый вокал нормализуется, выделенный вокал можно перепроверить по оригиналу. Длительная тишина обрабатывается отдельно с сохранением абсолютных времён.
- Автоматические метки и F8 используют упреждение **45 мс**. LRC сохраняет миллисекунды с тремя знаками после точки; ручные метки не сдвигаются.
- Закрытие крестиком отменяет расчёты, останавливает проигрыватели и завершает дочерние процессы через Windows Job Object. При закрытии новые фоновые задачи не запускаются.
- HTDemucs обрабатывает песню блоками с перекрытием и плавным стыком, а WAV записываются потоком. Анализ обложек и волновой формы использует ограниченные буферы. Тяжёлая задача дожидается отмены предварительного прослушивания. Поддержан RF64 для больших WAV.

Скачайте **SonicForge-Setup.exe** или распакуйте **SonicForge-windows-x64.zip** целиком. Windows 10/11 x64; для распознавания речи нужен AVX2. Модели включены в выпуск. Python не требуется для сборки и работы. Нейронные модели по-прежнему требуют свободную память, но аудиобуферы больше не растут вместе с длительностью песни.

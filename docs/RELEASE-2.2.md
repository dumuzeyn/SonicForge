# SonicForge 2.2

## Русский

Название, символ и композиция обложки теперь формируются совместно с учётом характера музыки. Для круглого отображения в плеерах текст размещается с запасом внутри круга. Исполнитель на обложке выключен по умолчанию; его можно включить вручную.

### Что изменилось

- Индивидуальная типографика: толщина, пропорции, наклон, интервалы и окончания букв учитывают энергию, динамику, тембр и эмоциональную окраску записи. Кириллица и латиница поддерживаются комплектными шрифтами.
- 40 семейств символов с музыкально обусловленными вариантами формы. Предметные образы требуют смысловой опоры в названии или включённом тексте песни; неизвестным названиям подбираются абстрактные формы. «Кружит» получает вращающийся образ.
- Общий план размещения названия и символа; дополнительные дуги, грани, ветви и лепестки связывают рисунок. Символ и сопровождающие элементы немного подняты для лучшей видимости в круглой обложке.
- Улучшено сглаживание букв, символов и вспомогательных фигур в предпросмотре и PNG. Большие изображения больше не растягивают низкое разрешение символа. Контраст текста проверяется по фактическим буквам.
- Сохранение настроек пользовательского стиля, управление распределением цветов палитры и более чёткий классический рисунок.
- Быстрый анализ звука с кэшем, отменой и отображением этапов работы.
- Связанный режим редактора: обработка может использовать текущий монтаж без отдельного ручного экспорта; исходные файлы сохраняются.
- Исправлено копирование текста из редактора песни. Пропущенное начало вокала восстанавливается только при подтверждении двумя акустическими окнами, без подстановки готового текста.
- Обновлены русская и английская инструкции.

### Загрузки

- **SonicForge-Setup-2.2.0.exe** — полный установщик Windows x64.
- **SonicForge-2.2.0-windows-x64.zip** — портативная сборка. Распакуйте папку целиком и запускайте SonicForge.exe вместе с каталогом `_internal`.
- **SHA256SUMS.txt** — контрольные суммы установщика и архива.

Для обновлённого оформления обложки нужно создать заново. Экспорт остаётся квадратным: безопасное размещение позволяет плееру обрезать его до круга. Система не гарантирует совершенно разные дизайны для музыкально похожих записей.

## English

Cover titles, symbols and composition now respond together to the recording's musical character. Titles stay inside an inset circle so circular player artwork retains the text. Artist lettering is off by default and can be enabled manually.

### Changes

- Music-conditioned lettering adjusts weight, proportions, slant, spacing and terminals using energy, dynamics, timbre and emotion. Bundled fonts support Cyrillic and Latin.
- 40 symbol families with expressive variations derived from audio. Literal objects require evidence in the title or enabled lyrics; unknown titles use abstract forms. Rotational titles receive a rotational motif.
- Coordinated title and symbol placement, with supporting sweeps, facets, branches and petals. The symbol and supporting elements sit slightly higher for better visibility in circular artwork.
- Improved antialiasing for text, symbols and supporting artwork in previews and PNG exports. Large symbols no longer upscale a low-resolution contour. Text contrast is measured on actual glyphs.
- Persistent custom cover settings, palette distribution controls and crisper classic artwork.
- Faster cached sound analysis with cancellation and visible progress stages.
- Linked editor processing can use the current mix without a separate manual export, while retaining source files.
- Fixed lyric-editor copying. Missing vocal openings are recovered only when two acoustic windows agree, without substituting supplied lyrics.
- Updated Russian and English illustrated guides.

### Downloads

- **SonicForge-Setup-2.2.0.exe** — complete Windows x64 installer.
- **SonicForge-2.2.0-windows-x64.zip** — portable build. Extract the entire folder and keep SonicForge.exe with its `_internal` directory.
- **SHA256SUMS.txt** — SHA-256 checksums for both downloads.

Regenerate existing covers to apply the new artwork. Exports remain square with text placed safely for circular cropping. Musically similar recordings can produce related designs.
